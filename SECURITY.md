# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, discussions, or pull requests.

Use GitHub's [private vulnerability reporting form](https://github.com/Shashank163007/Phishing-forensic/security/advisories/new) if it is available for this repository. If it is unavailable, contact the repository owner privately through GitHub.

Include a description of the affected component, impact, and steps to reproduce where safe. Do not include real email contents, personal information, credentials, API keys, or other users' data in a report.

The maintainers will acknowledge reports as soon as reasonably possible and coordinate any fix and disclosure with the reporter. There is currently no formal response-time or supported-version guarantee.

## Scope and safe testing

Only test systems and accounts that you own or have explicit permission to assess. Do not use this project to access, collect, or disclose other people's data.

The project is an AI-assisted detection tool. Its output can be incorrect and must not be treated as a guarantee that an email, URL, or sender is safe.
